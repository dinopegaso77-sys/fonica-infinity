# Fonica Infinity – sito web

Questi file pubblicano Fonica Infinity all'indirizzo
**https://dinopegaso77-sys.github.io/fonica-infinity/**

## Pubblicare (una volta sola)
1. Su github.com premi **+ → New repository**.
2. Nome: **fonica-infinity**, visibilità **Public**, poi **Create repository**.
3. Premi **uploading an existing file**, trascina tutti i file di questa cartella e premi **Commit changes**.
4. Vai in **Settings → Pages**. In «Branch» scegli **main** e **/ (root)**, poi **Save**.
5. Dopo 1–2 minuti l'app è online all'indirizzo qui sopra.

## Sul telefono o sul tablet
Apri l'indirizzo con Chrome → menu **⋮** → **Aggiungi a schermata Home** (o **Installa app**).
Compare l'icona Fonica come una vera app.

## Aggiornare
Quando ricevi un nuovo `index.html`, caricalo nello stesso repository (sostituisce il vecchio).
Chi usa l'app riceve l'aggiornamento alla successiva apertura.
